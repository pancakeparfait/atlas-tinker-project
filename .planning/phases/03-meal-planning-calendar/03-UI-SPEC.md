## Interaction Contracts

### 1. Calendar Week Grid (MEAL-01, MEAL-02)

```
┌──────────────────────────────────────────────────────────┐
│  < Month Week Range >          [Today]  [Plan ▼] [...]  │
├────┬────┬────┬────┬────┬────┬────┤                        │
│ Mon│ Tue│ Wed│ Thu│ Fri│ Sat│ Sun│                        │
├────┼────┼────┼────┼────┼────┼────┤                        │
│ 12 │ 13 │ 14 │ 15 │ 16 │ 17 │ 18 │                        │
│ ●B │ ●B │ ●B │ ●B │ ●B │ ●B │ ●B │                        │
│ ●L │ ●L │ ●L │ ●L │ ●L │ ●L │ ●L │                        │
│ ●D │ ●D │ ●D │ ●D │ ●D │ ●D │ ●D │                        │
├────┼────┼────┼────┼────┼────┼────┤                        │
│ ...│    │    │    │    │    │    │                        │
└────┴────┴────┴────┴────┴────┴────┘                        │
```

**Layout:**
- 7-column CSS grid (Mon–Sun), equal width columns
- 4 visible week rows (scroll or paginate for beyond 4)
- Column headers: abbreviated day names ("Mon", "Tue", etc.)
- Date number in top-left of each cell (14px label, weight 400)
- Three meal slot rows per cell: Breakfast, Lunch, Dinner (stacked vertically)
- Each meal row shows assigned recipe titles or empty-state "+" button

**Navigation:**
- ChevronLeft / ChevronRight icon buttons at top-left
- "Today" button (accent) at top-right — scrolls to current week
- Meal plan dropdown selector at top-right — switches between named plans

**Current day highlight:**
- Blue border (`border-blue-500`) around today's cell
- Light blue tint background (`bg-blue-50/10` or equivalent via Tailwind)

### 2. Meal Slot Interaction (MEAL-03, MEAL-04, MEAL-05, MEAL-07, MEAL-08)

**Empty slot (no recipes assigned):**
- Shows meal type label ("B") in small badge/chip (14px, weight 600, color-coded: amber/green/blue)
- Show "+" icon button on hover — 48×48px touch target (D-06)
- Click opens recipe assignment modal

**Populated slot (recipes assigned):**
- Lists recipe titles as compact chips (14px body, weight 400)
- Each chip: meal type dot (color) + recipe name + hover "×" remove button
- Hover "×" on recipe chip: triggers AlertDialog for removal confirmation
- Note text shown below recipes (14px, italic, muted foreground, prefixed with quote icon or pencil icon)
- Hover "×" on note: triggers AlertDialog for note removal
- Clicking recipe name opens recipe preview popover

**Notes:**
- Inline `Input` component with placeholder "Add a note..."
- Press Enter to save — note appears below recipes in slot
- Press Escape to cancel
- Notes are freeform text (e.g., "Leftovers", "Order takeout", "Eating out")

### 3. Recipe Assignment Modal (MEAL-04, D-07, D-08)

```
┌─────────────────────────────────────┐
│  Assign Recipes — Tuesday, June 16 │
│  ┌─────────────────────────────┐    │
│  │ 🔍 Search recipes...   [▼] │    │
│  └─────────────────────────────┘    │
│  ┌─────────────────────────────┐    │
│  │ Selected: [Pasta ✕] [Salad]│    │
│  └─────────────────────────────┘    │
│  ─────────────────────────────────  │
│  □ Recipe 1: Pasta Carbonara       │
│    15 min | ⭐ 4.5 | Italian        │
│  □ Recipe 2: Caesar Salad           │
│    10 min | ⭐ 4.2 | Salad           │
│  □ Recipe 3: ...                    │
│  ─────────────────────────────────  │
│           [Cancel]  [Add Recipes]   │
└─────────────────────────────────────┘
```

**Behavior:**
- Opens as `Dialog` (Radix) on click of "+" button in empty slot or slot body
- Title includes meal type and date (e.g., "Assign Recipes — Breakfast, Tue Jun 16")
- Search input at top filters recipe list (reuses recipe search pattern from `src/app/recipes/page.tsx`)
- Category/meal-type filter dropdown beside search (reuses existing filter UI)
- Recipe list shows: checkbox + recipe title + brief metadata (cook time, difficulty, servings)
- Multiple recipes selectable — selected recipes shown as chips above list
- Close action: "Cancel" button or Escape
- Confirm action: "Add Recipes" button (accent) — saves and closes
- Shows loading skeleton while recipe list loads
- Shows error state "Could not load recipes" + "Try again" if fetch fails

### 4. Recipe Preview Popover (MEAL-06, D-15, D-16, D-17)

```
┌─────────────────────────────────┐
│  ┌───────────┐                   │
│  │ 🖼 Thumb  │  Pasta Carbonara │
│  └───────────┘                   │
│  Prep: 15m | Cook: 20m           │
│  Difficulty: Medium              │
│  Servings: 4                     │
│  ──────────────────────────────  │
│  Ingredients:                    │
│  • 200g pasta                    │
│  • 100g pancetta                 │
│  • 2 eggs                        │
│  • 50g parmesan                  │
│  • ... (+3 more)                 │
│  ──────────────────────────────  │
│  A classic Italian pasta dish... │
│  ──────────────────────────────  │
│  [View full recipe →]            │
└─────────────────────────────────┘
```

**Behavior:**
- Opens as `Popover` (Radix) on click of recipe name/title chip in meal slot
- Title: recipe name (16px, weight 600)
- Thumbnail: primary image (if exists) or Utensils placeholder icon (100×80px rounded)
- Metadata row: prep time, cook time, difficulty, servings (14px, muted)
- Ingredient list: truncated to 5 items max, "+N more" indicator
- Description: excerpt of ~100 chars with ellipsis
- "View full recipe" link at bottom — navigates to `/recipes/[id]` (accent, weight 600)
- Closes on click outside, Escape, or "View full recipe" navigation
- Popover width: 320px max

### 5. Meal Plan Selector & Actions (D-11, D-12, D-13, D-14)

```
         [Meal Plan ▼]  [...]  
         ┌─────────────────┐    
         │ Week of Jun 9   │ ✓  
         │ Week of Jun 2   │    
         │ Week of May 26  │    
         ├─────────────────┤    
         │ Rename...        │    
         │ Archive          │    
         │ Delete           │    
         └─────────────────┘    
```

**Behavior:**
- `Select` component (Radix) for plan switching
- On initial visit to `/meal-plans`, auto-create first plan named "Week of [date]"
- Selected plan shows in trigger, dropdown lists all available plans
- Three-dot `[...]` icon button (DropdownMenu) for plan-level actions:
  - **Rename**: inline edit / small dialog with renamed input
  - **Archive**: AlertDialog confirmation with "Archive plan?" copy
  - **Delete**: AlertDialog confirmation with "Delete meal plan?" copy
- AlertDialog used for ALL destructive confirmations (consistent pattern)

### 6. Loading States

| Component | Skeleton Pattern |
|-----------|-----------------|
| Calendar grid | 7×4 grid of pulsing gray rectangles (skeleton cards) |
| Meal slot | Single line shimmer per slot row |
| Recipe assignment modal | 5 stacked skeleton list items with avatar+text shimmer |
| Recipe preview popover | Left thumbnail + 3 text line shimmers |
| Plan selector | Single line shimmer with dropdown indicator |

### 7. Error States

| Component | Error Display |
|-----------|--------------|
| Calendar view | Inline error banner above grid: "Could not load meal plans" + "Try again" button |
| Recipe assignment modal | Inline error in modal: "Could not load recipes" + "Try again" button |
| Recipe preview popover | Inline text: "Failed to load recipe details" |
| API mutation failure | Toast notification: "[Action] failed. Please try again." |
| Network offline | Passive — let TanStack Query retry, no separate offline banner |
