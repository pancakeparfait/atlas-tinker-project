Create Client Component:

**Props:**
```typescript
interface RecipePickerModalProps {
  open: boolean
  onClose: () => void
  mealPlanId: string
  mealDate: Date
  mealType: 'BREAKFAST' | 'LUNCH' | 'DINNER'
}
```

**State:**
- `selectedRecipeIds` - Set<string> for multi-select
- `noteText` - string for freeform note input
- `searchQuery` - string for recipe search

**Recipe list:**
- Use `useRecipes({search: searchQuery})` to fetch filtered recipes
- Render recipe cards with checkbox (not from existing page - checkboxes needed here)
- Click recipe card → toggle in selectedRecipeIds
- Selected recipes show checkmark or different background

**Selected chips:**
- Below search, show Badge/Chip for each selected recipe
- Click chip to remove from selection
- Visual feedback: "2 recipes selected"

**Note input:**
- Input field below selected chips
- Placeholder: "Add a note (e.g., 'Order takeout', 'Leftovers')..."
- Optional - user can assign recipes without note

**Actions:**
- Confirm button:
  - Disabled if no recipes AND no note text
  - Creates PlannedMeal for each selected recipe: `{mealPlanId, recipeId, mealDate: format(mealDate, 'yyyy-MM-dd'), mealType, servingsPlanned: 4, notes: ''}`
  - If noteText provided, creates PlannedMeal with recipeId=null: `{mealPlanId, recipeId: null, mealDate, mealType, servingsPlanned: 0, notes: noteText}`
  - Uses useCreatePlannedMeal() mutation
  - Chains mutations if multiple: `Promise.all([...mutations])`
  - On success: close modal, reset state
- Cancel button: close modal, reset state

**Modal layout:**
- Dialog component (Radix UI via shadcn/ui)
- Header: "Add to [Breakfast/Lunch/Dinner] - [date]"
- Body: Search input → Recipe list (scrollable) → Selected chips → Note input
- Footer: Cancel + Confirm buttons

**Reuse existing recipe UI:**
- Import recipe card component if exists, or inline simple card
- Don't rebuild full search system - use useRecipes hook with query param
